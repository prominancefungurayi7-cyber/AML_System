# MODEL V3 — STAGE 9 HARD-NEGATIVE AUDIT

The eight hard-origin families H1–H8 were generated as ordinary-looking behavioural counterparts. Their origin cohort is never used as a label. Each hard-origin family has both target 0 and target 1 rows under the universal observable evaluator, which preserves the distinction between generator provenance and decision-point evidence.

Hard-origin target counts are recorded by partition in the generation and structural-audit JSON. The audit also verifies that routine rows remain present and can receive positive targets only when a predicate is observable. No hard-negative metadata enters the raw transaction schema or development loader.

See [`V3_HARD_NEGATIVE_SPECIFICATION.md`](../design/V3_HARD_NEGATIVE_SPECIFICATION.md) for the precommitted family definitions.
