## 4. Generator contract and opportunity allocation

For every family and matched-hard allocation independently, while budget>=12 draw E=DU(12,min(20,budget)); residual<12 moves to routine and is logged. E includes all motif/context rows. For all except N3 set M=E-2 and R=2. For N3 use V/K above and R=E-M (nonnegative for all E). This explicitly replaces Stage 15A count laws for this separate challenge only; original V4 counts remain untouched.

Within each unit, independently random-permute active eligible-for-scheduling subjects (activity status only, not target eligibility) for each recipe and cycle without replacement before reuse. Agents similarly cycle. Select counterparties without self-links. No checking observed eligibility or target to accept a subject. Later intervals may revisit subjects; dependent episodes stay in one unit cluster.

Independent episode start uniform among fitting scored intervals, integer microseconds; uniform motif times within the declared duration, sorted, with first/last at endpoints except explicit order-swaps. No time quota conditioned on labels. Emit before updating state. Temporal support can fail.

Use all four Stage 15A context roles at probability 1/4 each and its padding/timing rules. Context always uses ordinary BASE amounts including S4/H3. Interleaved activity is counted in the fixed episode budget. No deleted pre-onset events.

Ordinary routine/history/context use BASE. Explicit challenge motif amount laws above override BASE for those recipes; use the identical law for their matched hard origins except declared historical anchoring, fraction or directional mechanisms. S3,A1,A2,A3 use BASE; N1/N2 use log-uniform USD30..500. All final values constrained to USD0.01..15000 by fresh numerical proposal rejection, then common Decimal half-up cents once. S4/H3 retain exact Stage 15A conditional mixture. For related amount vectors, reject/redraw the entire vector on numerical bound failure, never on a label. Independent shift applied before bounds and rounding: ordinary multiplication1.15, bounded Stage15A transform for S4/H3 only. No double shifting.

No generator-to-evaluator calls, forced labels, copied rows, support-driven retries or seed selection. Schedule once before labels; keep every event. Numerical/accounting failures and support failures are different.

Each family has120 intended opportunity events per unit; each matched hard stratum30; routine200 before declared residual transfers. Those are event budgets, not positive quotas. This deliberately enriched law is not a natural AML prevalence estimate.

### S1 — VariableFragmentBurst

**Current limitation:** Only development evidence; support does not validate a model. Fails both predeclared decision-point minima.

**Unchanged mechanism:** S1 max-share, count, value and acceleration; an early event need not satisfy the full conjunction.

**Opportunity:** Split a total drawn log-uniform USD 100..1000 by Dirichlet weights with alpha independently U(0.5,2) for each payment; spread over U(5,75) minutes. Both short-window and dispersed longer opportunities occur.

**Matched hard behaviour:** Use the same total/count law, with one random Dirichlet alpha=8 and others=1, or duration U(45,120) minutes (equal choice).

**Shortcut review:** Shared rounding/type rules; avoid an origin-specific total or cents signature.

**Independent requirement:** Both arms, fresh subjects and causal histories; common support and diversity objectives apply to all twelve families.

## 7. Support objectives, dependence and failure handling

200 independent Bernoulli observations have worst-case normal-approximation 95% half-width 1.96*sqrt(.25/200)=0.0693. This is only planning intuition; correlation worsens precision. Forty subjects, fifty episode/day clusters and twelve represented units guard concentration, not a claimed effective sample size. Each arm has twelve available unit clusters, so arm comparisons remain exploratory and uncertainty may be wide. Do not claim the original 300-row policy has been relaxed: these are new challenge objectives for a different estimand. If tighter original precision is required, this design is insufficient.

For **each** family: ≥200 positive decision points, ≥40 subjects, ≥50 episode/background-day clusters and ≥12 units; ≥20 positives in at least4 of6 fixed30d bins; maximum subject share10%, unit share20%, bin share40%. Each arm: ≥80 positives and ≥8 units. For each matched hard stratum: ≥200 union-target0 rows, ≥30 subjects, ≥12 units; near-boundary target0 ≥50 rows across ≥8 units. These objectives apply to all12 families, not just sparse ones.

Independent resampling cluster is whole local unit. Episode cluster=(unit,scenario_id); non-episode cluster=(unit,UTC day). Subjects and episodes within a unit are dependent; never sum them as independent sample size.

Retain first complete draw, publish only predeclared aggregate support PASS/FAIL before freeze, preserve detailed counts privately. Do not regenerate, relax rules, drop families, add events or change seeds. Failed technical correctness blocks all evaluation. Failed support blocks a full-family adequacy claim and automatic progression to feature/model work; a separate user decision may permit an explicitly qualified protocol without changing data/targets. Actual counts and failed objectives are released in the final frozen evaluation report, or in a separately authorized retirement audit after ending use as independent evidence, never as tuning feedback.

Challenge prevalence is measured, not targeted. No acceptance loop for class balance. Metrics undefined on empty classes are null with reasons; binary comparison requires both classes and adequate negative support.

Support PASS alone does not establish adequate precision. If simultaneous family-recall interval width exceeds0.20, withhold a precise family conclusion even if counts pass; display estimate, counts and limitation. Arm/slice intervals require >=8 represented units; otherwise exploratory counts only.

No support guarantee follows from the budget. Especially S4 and conditional negative slices may remain sparse. The protocol commits to a bounded opportunity study and honest withheld conclusions, not inevitable certification. An implementation feasibility failure must stop before production; it cannot silently expand the budget.

## 9. Separate success criteria

Target correctness: independent fixtures and exact observable-only replay; no target/provenance shortcuts. Support adequacy: all declared support and precision conditions; per-family failures retained. Independence: separately controlled custody, commitment and freeze/access log intact. Each gate has its own status; no aggregate metric substitutes for a failed gate.

Acceptable model behaviour is a future assessment under the following predeclared synthetic-research tolerances:

- All technical/independence gates PASS and relevant support/precision objectives met

- Pooled suspicious recall95% lower bound>=0.80

- Each family simultaneous recall lower bound>=0.70

- Each domain recall95% lower bound>=0.75

- Overall FPR95% upper bound<=0.10

- Each matched-hard FPR upper bound<=0.15; use simultaneous12-stratum Bonferroni bounds

- Shifted arm family recall drop reference-minus-shifted upper95% bound<=0.15 for adequately supported families; unsupported differences INDETERMINATE

Conjunction. Any definite failure => behavioural criterion not met. Missing/inadequate support => indeterminate, never PASS. Report every metric regardless. Macro F1 alone cannot establish success. These conservative illustrative synthetic-research tolerances require explicit protocol approval and are not derived from challenge outcomes.

These numerical criteria are proposed research standards requiring protocol approval; they are not empirically justified operational risk limits or a promise of improvement. Failure or wide uncertainty is reportable scientific evidence. Real-world effectiveness remains unverified regardless of score.
